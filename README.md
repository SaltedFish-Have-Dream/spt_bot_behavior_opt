# spt_bot_behavior_opt

轻量化 SPT 拟真 Bot 行为模组。当前版本为 **0.3.0 开发验证版**：补充近距脚步伏击、失视短距突击、掩体换位、战术手雷和距离 ADS。此前的受击避险、同层交战记忆、小队分工及射击安全继续保留。所有新增行为只针对本机真人玩家，尚需局内实测。

## 当前功能

- PMC 的反应、瞄准稳定、听觉误差、记忆时长和战术倾向随等级线性变化；默认成长区间为 1～60 级。
- 普通 Scav 使用固定模板；狙击 Scav 保留定点定位；Boss、护卫、Raider 与其他特殊角色沿用原生逻辑。
- 保存个人视觉和带误差的听觉快照，限制丢失视线后的直接瞄准与开火；执行调查、搜索、交战、局部掩体和原生恢复动作。
- 共享物理与寻路预算、轮转查询、有限记忆、超时和卡住回退，提供低频汇总日志。
- 玩家枪声：听到后 0～30 米快速警戒，30～120 米按距离和能力估计区域搜索；超过 120 米未受枪弹威胁不额外响应。
- 玩家命中或 2.5 米内实际近弹：优先局部掩体；只有本人中弹、掩体已证实不可用且当前看不到玩家时才尝试合法趴伏。安静五秒后，身体与弹药允许才有限推进。命中时还会限频通知 20 米内同组受管成员。
- 在自有掩体处被玩家命中后暂时排除该点；高压优先隐蔽，压力回落且在有效掩体、有真实视线时尝试还击。接近搜索点时短暂停看，同一区域最多两次；普通视线变化不再随意打断有效掩体移动。
- PMC 出生时固定选择谨慎、均衡或主动风格，仅小幅调整有掩体时的战术选择倾向；等级成长仍独立生效，Scav 保持固定模板。
- 玩家命中后，二十米内同组受管 Bot 共同避险；有合格成员时只选最近的一人于安全窗口后推进，其他人守点观察或凭真实视线还击。无合格队友时受害者沿用原有推进规则。
- Bot 亲眼看见本机玩家且本插件实际控制交战时，最多每半秒按距离和武器支持集选择单发、连发或全自动；换弹及正在射击时不切换，交还控制时尝试恢复原模式。
- 曾经完成反应准备的 Bot 在八秒内亲眼看见玩家从原区域重新露头时，不重复等待模组反应计时；若确实无掩体、当前仍看见玩家，低压 Bot 可在短暂受惊后尝试自卫，无需先趴下。原生瞄准就绪和两道射击安全检查仍必需。
- 持续目视的近距同层交战后，Bot 记住最后目击位置 18～27 秒；脚步声更新估计位置时不再缩短已有记忆。失视后仍不能隔墙精确瞄准或射击。
- 近距玩家脚步触发短暂停看；近期亲眼看见玩家后，PMC 可按等级线性提高的机会沿旧点短距突击。失视掩体可有限换位；对旧目击点的战术手雷受友军安全、原生轨迹和全局额度限制。
- 真实目视时贴脸倾向腰射、远距倾向 ADS，中距保持现态；交还原生时按控制权归还瞄准选择。SAIN 中依赖隐藏敌人状态或盲射的机制未照搬，完整对应关系见 [0.3.0 战斗战术适配](docs/v0.3.0-combat-tactics.md)。

依赖 **SPT 4.1.5 / EFT 0.16.9.5-40743 / BigBrain 1.5.0 / SPT-Waypoints 1.9.0**，不依赖 SAIN。SAIN 与 ORBIT 会接管相同的行为链路，插件启用冲突保护，安装前需要停用这两个模组。

## 本机构建

在项目目录执行：

```powershell
& '.\tools\Build.ps1' -Package
```

脚本默认使用上一级目录的 `net_sdk/dotnet-sdk-10.0.401-win-x64` 和本机 `EFT v4.1` 安装。其他位置可传入 `-SdkRoot` 与 `-GameRoot`。首次还原可能需要联网。

构建依次核对本地游戏接口及 Waypoints 安装、编译 Release 工程、运行独立行为检查，最后输出 `dist/AiBehaviorOpt-0.3.0.zip`。仅打包两个自有 DLL 与说明文件，不修改游戏安装，不修改全局 SDK 环境。
