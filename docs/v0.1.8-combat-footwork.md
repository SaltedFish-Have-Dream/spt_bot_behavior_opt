# 0.1.8 近距交战主动侧移

目标环境：SPT 4.1.5、EFT 40743、BigBrain 1.5.0、Waypoints 1.9.0。本版参考本地 SAIN v4.5.1 的交战设计，自行实现有限的近距交战换位，没有复制 SAIN 源码或加载其程序集。0.1.8 尚未经过游戏内实测。

## SAIN 从哪些方面改善交战体验

| 方向 | 本地 SAIN 源码中的做法 | 本模组当前取舍 |
| --- | --- | --- |
| 近距交战移动 | `SAIN/Classes/Bot/Decision/DogFightDecisionClass.cs` 根据目标已知、距离、弹药和当前动作选择贴身交战；`SAIN/Classes/Bot/Mover/DogFight.cs` 执行移动 | 本版只对亲眼看见的本机玩家，在没有已验证掩体时提出一次短距侧移，不扫描其他敌人，不替换原生近战系统 |
| 掩体和暴露 | `EnemyDecisionClass.cs`、掩体分析器根据暴露、压制、时间和路径重新选位 | 已有玩家受击掩体失效、挡枪换位与完整路径验证；危险或可用掩体优先于本版主动侧移 |
| 压制与攻守转换 | `SAINBotSuppressClass.cs` 累积并衰减受压状态，决策层据此抑制激进动作 | 已有玩家命中/近弹压力及危险五秒窗口；本版受压时禁止主动侧移，继续优先避险 |
| 武器节奏 | `Firemode.cs` 按距离和武器支持能力切换模式，`Firerate.cs` 结合距离、武器类别与随机量确定射击间隔 | 仍由 EFT 原生武器处理模式、后坐力、弹道与动画；本版不叠加一套未知兼容性的枪械调参 |
| 小队互补 | `SquadDecisionClass.cs` 根据同目标成员的搜索、撤退或压制选择协作 | 当前仅有玩家直接命中后的 20 米同组单跳告警；完整掩护与单人推进留给独立阶段 |

这些是源码设计观察，不是 SAIN 与本模组的同场景胜率或帧时间对比。尤其不能直接读取隐藏玩家的健康、装备或实时位置来模拟“聪明”。

## 本版规则

只有本插件实际取得 BigBrain 层控制、当前状态为 `Engage`、原生个人视觉真实看见本机玩家，并且玩家位于水平距离六至二十五米时，才考虑主动换位。Bot 必须在同一交战窗口稳定目视至少 1.5 秒；狙击 Scav、已有有效掩体、正受玩家枪弹威胁、正在恢复、已有移动/查询或射击验证未结束时均不触发。没有已验证掩体不代表现场一定空旷，具体侧移位置仍以导航检查为准。

候选取与当前玩家视觉方向垂直的三米侧点，Bot 固定左右倾向，不逐帧重抽随机。每个目标连续交战最多主动申请一次；失去视觉超过六秒或换目标后才建立新窗口。短暂遮挡不会重置名额。挡枪换位已提出时，占用主动侧移名额；主动侧移成功排队后，挡枪反馈至少等待八秒并重新累计三次真实阻挡，避免马上再次换位。

候选仍通过原有队列执行导航源点、目标投影、完整路径、终点与十二米绕行上限检查；查询失败不会伪造成已移动。真正提交路径后由原生移动器执行，移动中瞄准与开火继续经过本模组真实视觉、武器、世界障碍和友军枪线验证。状态切换、玩家危险、治疗换弹、掩体移动或 BigBrain 交还控制可随时中断。没有新增射线、全场敌人扫描、独立寻路额度或新前置。

配置 `Tactics.CombatFootwork=true` 默认开启，可改为 `false` 并重启以做局内对照。启动日志 `COMBAT_RULES` 记录实际开关和触发边界。`COMBAT_FOOTWORK_REQUESTED` 只表示候选已经排入队列；要确认实际行动，应继续看同 Bot 的 `QUERY_SUCCEEDED`、`MOVE_STARTED`、`MOVE_PROGRESS` 和 `REPOSITION_ARRIVED reason=open-fight`。若查询失败，看 `QUERY_FAILED kind=Reposition`，不能将一次申请算作完成换位。

建议在海岸线测试玩家与普通 PMC/Scav 距离 6～25 米、双方互相可见且附近没有合适掩体的场景；再对照贴脸、三十米外、Bot 已在掩体、正在受压或换弹的场景。留意是否出现移动中开火过准、靠墙反复寻路、抢占原生撤离、或已有挡枪换位后连续横跳。上一版日志不能作为 0.1.8 的行为与性能验收。

性能影响：**低，静态分析预估，未实测**。每个受管 Bot 增加固定大小的交战窗口状态；视觉更新和资格判断为常数时间，成功排队的主动路径每个连续交战窗口最多一次。大量 Bot 同一时刻在六至二十五米范围与玩家目视交战、且都没有掩体时，短距路径请求可能集中竞争现有每帧一次完整路径计算额度，造成排队或截止；原生同步导航仍可能构成单帧峰值。服务端和网络路径没有新增工作。
