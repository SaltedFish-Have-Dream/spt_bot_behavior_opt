# 0.1.1 海岸线实测后调整

日期：2026-09-22。依据为 [0.1.0 海岸线测试记录](playtests/2026-09-22-shoreline.md)。本版修复和诊断已完成本地验证，尚未进入游戏复测。

## 修改落点

| 问题与证据 | 本次处理 | 下一局关注 |
| --- | --- | --- |
| 停用 Bot 的代次达到约 4.8 万；源码确认每帧扫描两条队列 | 激活状态按边沿处理；动作或原生射击排队才登记清理责任；重复释放不扫描队列、不递增代次；恢复后及时唤醒决策 | `Deactivated/Reactivated/ResourceReleased`，代次不再随停用帧数增长 |
| 安全检查可能用尽决策时间片；日志一段时间保持调查状态，具体局内原因未完全确认 | 每帧保障一次到期活动项的公平轮转；其余决策仍遵守原软阈值；线索过期/搜索完成直接退出，保留正在执行的原生恢复 | `decisionWaitMaxMs`、`decisionOldestDueMs`，调查结束后是否正常交接巡逻 |
| 多次调查因超距结束 | 沿用 Scav 25 米 / PMC 60 米范围，声音误差计算后在入库前过滤，接管前再次核对；不删除已有视觉线索；狙击模板仍原地观察 | `SoundOutOfRange/ClueOutOfRange` 与听到近处枪声后的实际响应 |
| 36.651 毫秒峰值无法归因，且旧计时可能漏掉 LateUpdate 后的入口 | 固定容量嵌套计时，八个阶段、调用峰值、最差帧组成及局内时刻；在下一帧结算上一帧；增加活动/停用数与日志阶段 | `TIMING` 中 `peakT` 和各阶段 `AtPeakMs`；不能将旧峰值全部归因于清理 |
| `BrainSkipped=1` 但首次脑型明细被限频淹没 | 每局前 32 种角色/脑型组合独立保留首次明细，之后一次容量提示；总计数不丢失 | `BRAIN_SKIPPED` 中具体角色与脑型；仍保留原生行为 |

本次未调整 PMC 成长曲线、Scav 能力模板、层优先级或物理/导航配额。新增及修改方法带中文说明，关键调度与清理逻辑带逐行注释。

## 本地验证

- 目标游戏十二项 API 签名、六个角色常量检查通过。
- 完整客户端和行为检查工程 Release 构建通过，零警告、零错误。
- 二十三组纯逻辑场景、55,292 条断言通过；覆盖五万次停用、原生层排队后清理、持续超预算轮转、调查边界/到期、首次兼容诊断和嵌套计时。
- 安装包为 `dist/AiBehaviorOpt-0.1.1.zip`，包含两个自有 DLL 与使用/日志说明。构建不直接覆盖游戏安装。

这些检查未执行真实 Unity 行为，不能证明停用恢复后的巡逻、交战和治疗结果；需要下一局确认。旧版日志和安装包保留用于对照。

## 复测建议

关闭游戏后同时更新两个 DLL，重启确认 `START version=0.1.1`。沿用上一局海岸线和 AI Limit 配置，更容易比较。观察远处 Bot 恢复活动、听声调查后回到巡逻、遮挡后再接敌，以及正常进出战局。遇到发呆、持续转向、不开枪等现象，记录大概时间和位置即可，日志可按 `peakT`、决策等待和状态变化对齐。

性能影响预估为 **低（静态分析，未局内实测）**。稳定停用期减少重复清理，计时与去重使用固定容量结构；每帧保障一次到期决策可能越过软时间片，但不扩大物理配额。集中接敌、复杂区域单次同步导航、较低帧率下积压决策或同步日志写入阻塞仍可能形成瓶颈。新版本计时范围比旧版更完整，平均值与峰值不能直接当作同口径 FPS 对比。
