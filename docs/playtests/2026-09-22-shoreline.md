## 性能结果与限制

插件插桩累计 76,857 帧，工作耗时平均 **0.062 毫秒**、峰值 **36.651 毫秒**；超过 0.5 毫秒软预算的帧为 **562 帧，约 0.73%**。这些数字来自插件已有计时，覆盖部分新增入口和事件日志开销，不包括完整游戏 AI、全帧时间、周期汇总写入、完整 GC 或进程调度成本。

目前可将本局记录到的常态工作开销评为 **低**，但已观测到需要调查的明显峰值，不能据平均值宣称已经达到全部性能目标。长时间原生/未激活阶段会降低累计均值；同时运行 AI Limit 也改变了活动负载。本局没有原生或 SAIN 的同场景对照，不能计算优化百分比或容量上限。

最高峰首次出现在 `t=420.13～450.13` 的汇总区间，首次交战约在 `t=443.95`；该区间新增路径计算为零，故不能直接归因于本插件显式 NavMesh 寻路。现有统计没有逐阶段、逐帧耗时，尚不能确定是首次执行、物理调用、日志写入或其他因素。

## 已定位问题与后续验证

1. **未激活 Bot 重复清理。** `BotAgent.SafetyTick` 对非 `Active` Bot 每帧调用 `Release`；`Release` 在检查 `Controlled` 之前扫描两个固定容量队列并递增 `Generation`。日志中 Bot 3 的代次达到 48,709、Bot 8 达到 48,102，远超实际行为切换量。这条重复工作路径由源码直接确认；与 AI Limit 停用场景相符，但不能将本局全部开销或峰值归因于它。后续应只在活动状态/控制权发生变化或确有待清理资源时执行，保留旧请求失效与再激活安全边界。
2. **补充分阶段峰值归因。** 针对安全检查、决策、动作、物理/寻路和日志开销分别采样，区分首次使用与后续稳定交战。避免为测量再次引入逐帧字符串或无限日志。
3. **保留兼容旁路证据。** 一次 `BrainSkipped` 没有保留下具体脑型明细。后续应为首次未知脑型保留独立的限频记录，不能直接扩大白名单接管。
4. **扩大验证场景。** 需要单独验证远处停用/靠近激活、连续两局、普通 Scav 与 Boss/护卫隔离、等级对照、动态门和不可达位置，以及无 AI Limit 或固定活动负载下的原生/本插件/SAIN 对照。本局的角色明细受限频影响，不能宣称这些场景全部通过。

日志还出现了 Volcano 配置本地化扩展的枚举键冲突，以及 MenuOverhaul 的环境 UI 警告。没有日志证据把它们与本插件行为失败建立因果关系，未将其归类为本插件故障。

本轮只归档和分析实测结果，未修改行为实现或游戏配置。报告与文档更新的游戏性能影响为 **极低**：不进入游戏执行路径，没有新增战局运行瓶颈；上面的运行开销与问题属于被测版本。
