# 0.1.2 玩家专属行为增量

日期：2026-09-22。SPT 4.1.5 / EFT 0.16.9.5-40743 / BigBrain 1.5.0。本版为待游戏实测的开发包，保留 0.1.1 的生命周期、调度与计时修复。

## 范围与预期行为

只有本机真人（`IsAI=false && IsYourPlayer=true`）能触发本模组新增行为。AI PMC 不因阵营名包含 PMC 被误判为玩家。AI 来源或未知来源的视觉、听觉、目标选择、瞄准、扳机入口沿用原生；AI 弹道不进入近弹队列。

已有玩家视觉、脚步、等级反应、记忆、搜索、掩体、恢复和开火验证也遵守该范围。没有玩家情境的 Bot 不运行新增高层决策与查询，仅保留来源及生命周期检查。混战中切换到 AI 目标时清理旧玩家任务、交还原生；玩家新造成的五秒紧急危险可暂时优先于互战。离开危险后仍在与 AI 交战的 Bot 继续原生战斗，不强行转头追玩家。

受管角色仍为 PMC、普通 Scav、狙击 Scav。Scav 的能力固定，PMC 按原有等级曲线变化；狙击 Scav 不离岗。Boss、护卫、Raider 保留原生行为，本次没有为它们套用通用追击/趴伏动作。没有扩展到 Fika 远程玩家。

| 玩家事件 | 行为 |
| --- | --- |
| 已听见、距离 0～30 米（含 30）的枪声 | 保存射击时的位置，唤醒视觉扫描和决策，两秒内不受新增等级等待限制；只能在真实视线、原生瞄准与武器条件成立时开火 |
| 已听见、距离超过 30 至 120 米（含 120）的枪声 | 生成一次带误差位置，定位误差同时受距离和角色能力影响，分段靠近并搜索 |
| 超过 120 米，仅有枪声，无命中或近弹 | 不触发新增反应；已有合法视觉或仍未过期的危险不会因此被清除 |
| 任意距离玩家枪弹命中 | 受害者立即进入 `Evade`，获得控制后降低姿态，优先查询/前往附近验证可达且遮挡威胁的掩体 |
| 实际飞行线段或弹着距 Bot 中部 2.5 米内 | 形成近弹危险，同样进入避险；来源使用实际玩家枪弹，不凭整张地图的枪声猜测压制 |
| 有限掩体候选验证失败 | 尝试原生合法趴伏；近身不足八米、姿态受限、治疗/换弹进行中不会强制趴伏 |
| 距最后一次危险满五秒 | 健康、弹药与原生恢复状态允许时进入 `Advance`，向最后合法快照区域有限推进；缺弹/低血量不强制前压 |
| 玩家命中 Bot，20 米内存在同组受管成员 | 限频发送一次受击告警；每个接收者形成自己的危险估计，不重复传播，不共享精确实时位置 |

“立即”指不等待普通动作承诺、及时唤醒并设置紧急状态。实际动作受 BigBrain 更高优先级层、活动状态和当前原生手部动作限制；路径计算仍分帧且使用全局额度，不保证同帧到达掩体。额度排队或超时不等于查明没有掩体。有限候选失败也不能证明整个周围绝无其他可用位置。

近枪精确的是**声音发生时的位置**，不是透视锁定。枪声仍要求原生 `wasHeard` 成立；没听到但确有近弹/命中时走独立危险入口。原生完成碰撞后的实际终点用于裁剪弹道，不将轨迹无限延伸到墙后；墙面附近弹着仍可能使邻近 Bot 警戒。手雷碎片、榴弹发射器轨迹和未知武器不进入新增近弹入口。

## 定位与推进

PMC 基础听觉误差由 1 级 8 米线性降到 60 级 3 米；普通 Scav 固定 10 米，狙击 Scav 固定 8 米。30 米外的枪声误差乘数从 0.5 连续增至 120 米的 2。以 120 米为例：PMC 1 级误差半径 16 米、60 级 6 米，普通 Scav 20 米、狙击 Scav 16 米。近距统一快速警戒不会提高瞄准散布、改写伤害或绕过枪线验证。

直接命中与近弹只给带误差的危险区域；同一射击区域持续压制时复用估计，避免每段弹道重新抖动使掩体不断失效。普通枪声不刷新五秒危险窗口；新的命中、近弹和同组受击告警可刷新。近弹通知在单 Bot 上合并 0.15 秒，直接命中不受此合并限制。

枪声/危险调查寿命为 `clamp(距离 / 3 + 6, 12, 45)` 秒，读取不续期。每次朝目标移动最多 12 米，最多搜索三个位置。分段到达后继续规划，最终合法导航投影也算到达，避免在墙边重复请求同一路径。原有脚步/普通视觉搜索仍保留 Scav 25 米、PMC 60 米的范围；枪声/危险调查不被这两个旧半径截断。目标到期、候选耗尽、死亡、停用或失去控制权都能退出。

## 工作量与日志

- 紧急、射击、普通查询共享原有物理/寻路额度，依次轮转；总容量不超过 `min(4 × 受管 Bot 数, 256)`。紧急请求 2.5 秒到期，普通查询一秒到期。
- 紧急队列每帧至少有一次推进机会；不提高路径或射线的全局令牌额度。
- 玩家弹道固定队列 64 段，0.2 秒到期；纯几何筛选每秒补充 6,000 次、单帧最多 256 次，无新增近弹物理检测。过载直接舍弃段并计数，不保证拥挤/霰弹场景每次擦弹都能响应。
- 友方告警额度每秒补充四次、突发容量一次；只发一跳，不堆积重播。直接受害者独立处理，因此广播合并不等于漏掉直接命中。
- 命中或近弹入口自身异常时记录一次 `PLAYER_EVENT_FAILED`，该局关闭对应增强，保留原生伤害与弹道。单 Bot 执行异常仍使用既有 `FALLBACK` 降级。

日志新增 `PLAYER_RULES`、`PLAYER_SCOPE`、`PLAYER_SCOPE_ENTERED/LEFT`、`PLAYER_DANGER`、`DANGER_PRONE`。`PLAYER_DANGER.kind` 区分 `hit`、`near-bullet`、`ally-hit`；动作实际执行仍需结合 `ACTION_ENTERED`、`QUERY_SUCCEEDED`、`MOVE_STARTED` 判断。`PLAYER_SCOPE` 显示参与数、紧急积压、弹道丢弃/到期、广播合并及入口是否启用。普通明细仍有全局/单 Bot 限频，最终汇总保留计数。

**性能影响：低，静态分析预估，未实测。** AI 来源被提前排除，不为全地图 AI 交火新增路线/射线；新增内存和计算有明确上限。瓶颈条件包括：玩家近距离用霰弹或连射同时威胁许多 Bot、多人同时请求掩体、复杂房间单次同步 NavMesh 查询慢、日志监听器阻塞。软时间片不能中断已开始的同步游戏调用。近弹额度不足会牺牲部分通知，需结合丢弃数与实战效果调参，不能只看较低耗时。

## 已验证与下一局重点

本机构建完整客户端及行为核心，Release 零警告、零错误；通过 33 组纯逻辑场景、55,991 条断言，核对目标程序集 19 项 API 与六项角色常量。新测试覆盖真人过滤、混战交接策略、枪声距离边界、等级误差、五秒危险窗口、恢复优先级、分段搜索、真实线段几何、队列过载/过期/游标与固定额度。未启动游戏验证本版 Harmony 挂接、声音事件路径、卧姿动画、实际掩体与导航结果；旧版海岸线日志不代表本版实测结果。

安装时关闭游戏，同时更新两个自有 DLL，重启确认 `START version=0.1.2` 和 `READY patchedMethods=11 expectedMethods=11`。本次构建只生成工作区包，没有替换游戏文件。重点观察：

1. 20 米处开枪打偏：Bot 转向/寻找玩家；有直接视线时尝试攻击，遮挡时不得穿墙精确射击。
2. 60 米与 110 米处开枪打偏：分别观察朝估计区域搜索；比较 PMC 等级和固定 Scav，不要求每次随机偏移完全一致。
3. 130 米外朝远离 Bot 的方向开枪：不额外唤醒；相同距离命中则立即避险。
4. 数十米处让子弹擦身或击中附近地面：对照 `kind=near-bullet`；打向远离 Bot 的地面不应全体避险。
5. 有/无掩体地形分别命中：看查询、移动或合法趴伏；停止制造危险五秒后，看健康 Bot 推进，重伤/缺弹先恢复。
6. 命中小队成员：20 米内同组成员避险，远处/异组成员不因这次告警加入；连射时观察广播合并计数。
7. 玩家保持隐蔽且不制造线索，仅观察 AI 互战：增强参与数不应因 AI 枪声扩大，原生交战应正常。
8. 玩家与两组 AI 混战、AI Limit 停用再激活、连续两局：检查来源切换、旧查询撤销与 `RAID_END remainingBots=0 pending=0 bulletPending=0`。

测试结束、再次启动游戏前保留 `BepInEx/LogOutput.log`，或运行项目 `tools/Collect-Logs.ps1` 归档。记录地图、异常的大致时间和当时距离，便于把看到的动作与日志对应起来。
