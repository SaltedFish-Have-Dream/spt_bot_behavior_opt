# 0.2.0 SAIN 交战思路的轻量实现

目标是让 Bot 对本机真人玩家的行为形成可解释的闭环，而不是移植 SAIN 的类、补丁或全量视觉系统。参考版本是本地 `reference/SAIN` 的 v4.5.1 固定提交 `2d1d9257dbb3af535e9189e6181311f6355aec27`；目标仍为 SPT 4.1.5 / EFT 40743 / BigBrain 1.5.0 / Waypoints 1.9.0。以下为源码与独立测试结论，尚非 0.2.0 局内测量。

| SAIN 思路 | 本模组的执行方式 | 边界 |
| --- | --- | --- |
| 来源不同的敌情记忆、听声定位与再次发现 | 既有个人视觉、玩家枪声、近弹、直接命中与队友告警分别保留来源和寿命；失视守旧出口、同区域再次目视缩短准备 | 不读取遮挡后玩家实时位置，不替换原生视觉 |
| 掩体、受压和恢复的因果链 | 既有局部可达掩体、命中后短期失效点、压力衰减、合法趴伏及五秒后评估推进 | 掩体和路径继续受共享物理、导航预算限制 |
| 交战风格与能力分离 | 本版 PMC 出生时固定谨慎、均衡或主动风格，战术概率仅 ±0.12；等级仍线性决定能力 | 普通 Scav 均衡固定，Boss/特殊角色保持原生 |
| 贴脸控距与射界换位 | 既有 1～6 米后撤、6～25 米侧移及挡枪换位共用一次名额 | 必须亲眼看见玩家，路线需完整验证 |
| 小队互补任务 | 玩家命中时复用 20 米同组单跳告警，最近的合格队友取得一个推进名额；其他队友避险后守点、真实目视时还击 | 每次告警独立选择；不做全图通信、盲射或多人冲锋 |
| 武器模式与距离适配 | 本版真实目视交战每 0.5 秒检查一次武器模式支持集；≤22 米优先全自动，≥55 米优先单发，中距保持可用现态 | 正在射击、换弹、未接管时不切；原生射速、散布和后坐力不改 |

小队推进需要命中由本机真人玩家造成、同组成员在受害者 20 米内、活动且有弹，不能正在换弹或治疗。所有收到告警的成员先执行既有避险；五秒危险窗口结束后，获选者仍受伤势、掩体、完整路径和线索寿命限制。没有合格队友时，受害者沿用原有规则。其他成员没有亲眼看到玩家时原地观察，看到玩家后可按现有射击安全规则还击。单人名额只约束本次告警的 `Advance` 行为，不接管游戏原生的小队系统。

武器模式切换仅发生于本插件已取得 BigBrain 控制、当前目标为本机真人、个人视觉真实有效的瞄准分支。只选武器声明支持的模式；无须切换时不写物品或动画。交回原生或更换武器时，如果当前模式仍等于本插件最后写入值，则恢复进入接管前的模式；若其他系统已改写则放弃所有权。中距 22～55 米保持当前受支持的模式，减少距离边界附近反复切换。游戏中的射击动作仍由原生武器与瞄准系统完成。

本版未实现 SAIN 的多身体部位视觉替换、全地图动态掩体、敌人治疗/换弹的隐藏状态读取、复杂压制盲射、完整小队战术树和后坐力重写。这些机制需要额外物理查询、持续对象扫描或侵入原生射击链路，不适合未经局内性能验证直接合入。

## 局内核对

1. 同时替换两个自有 DLL 后重启游戏，确认 `START version=0.2.0`、`SAIN_ADAPTATION_RULES` 三个开关均为 `True`、`READY` 目标数正确。SAIN 和 ORBIT 仍需停用。
2. 海岸线选择一组受管 PMC，玩家直接命中一人后检查 `PLAYER_DANGER kind=hit/ally-hit`、`SQUAD_ADVANCE_SELECTED selected=True/False`、五秒后是否仅一人进入 `Advance`；其他成员可出现 `Observe` 或真实目视后的 `Engage`。没有 `SQUAD_ADVANCE_SELECTED` 时结合告警额度、距离、弹药和活动状态判断。
3. 用支持单发与全自动的武器分别在 22 米内、22～55 米、55 米外让 Bot 真正目视玩家；核对 `FIRE_MODE_CHANGED`、原生射击结果及交还时的 `FIRE_MODE_RESTORED`。单发武器不应出现全自动切换；正在连射或换弹时不切换。
4. 对比同地图、相近 Bot 数量与配置下的 `TIMING`、`COUNTERS`、实际动画及移动；检查原有蹲起、无反应、路径失败与控制权交接是否回归。日志事件说明见 `playtest-logging.md`。

**性能影响：低，静态分析预估，未实测。** 固定风格在 PMC 构造时只抽取一次；小队选择复用已有每秒最多四次的同组命中告警遍历，并只保存一个值候选；武器模式只在有效目视瞄准中每半秒检查一次，不新增射线、碰撞体扫描或寻路任务。若许多 Bot 同时目视玩家且武器模式反复变化，原生武器状态和动画调用可能集中在同一帧；若同一时段又有多人受击，既有掩体与短距路径查询仍可能使主线程出现同步峰值。应以新版本局内 `TIMING` 和完整帧数据核对，不能用旧版海岸线均值宣称收益。
